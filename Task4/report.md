# Основные проблемы

1. Инфраструктура
  - Недостаток ресурсов на серверах на серверах
  - Отсутствие автоматизации

2. Программное обеспечение
  - Несовместимость новых компонентов с существующей системой
  - Монолитная архитектура

3. Интеграция
  - Отсутствие версионирования контрактов
  - Сложности с синхронизацией данных

4. Персонал
  - Ручные операции
  - Необходимость обучения персонала новым технологиям и инструментам
  - Маленький штат

5. Процессы
  - Нет процессов управления инцидентами
  - Нет процессов управления изменениями

6. Данные
  - Нет категорий данных
  - Нет контроля доступа
  - Все данные на одном диске
  - Отсутствие золотого источника

### Рекомендации

- Оптимизация инфраструктуры, возможно переезд в облако
- Постепенный переход на микросервисную архитектуру
- Ввести версионирование контрактов, использовать очереди сообщений
- Обучение персонала, повышение автоматизации
- Внедрение процессов управления инцидентами/изменениями
- Управление данными: категоризация, контроль доступа, защиты данных

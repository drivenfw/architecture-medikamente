### Анализ безопасности системы

#### 1. Конфиденциальные данные, которые не учтены во внутренних системах:

- Персональные данные пациентов (ФИО., дата рождения, телефон, e-mail, адрес прописки, место работы или учёбы)
- Медицинские данные (заболевания, результаты анализов, заключения специалистов)
- Финансовые данные (информация о платежах, счетах, банковских реквизитах)

#### 2. Анализ текущего состояния

Текущее состояние:

- Данные хранятся в Excel, JPG, PDF и других форматах без аудита действий
- Внутренние потоки данных между IT-продуктами не контролируются
- Ограничения по передаваемым данным обусловлены только бизнес-процессами компании
- Нет ограничений на доступ к данным со стороны систем обработки, кроме доменной аутентификации

#### 2. Аудит мер по обеспечению безопасности данных

Проблемные зоны:

- Отсутствие контроля доступа
- Отсутствие контроля за внутренними потоками данных
- Недостаточные ограничения на доступ к данным
- Отсутствие аудита действий с данными
- Риск утечки данных из-за хранения в непосредственной близости к пользователям
- Отсутствие шифрования данных
- Отсутствие тегирования данных

#### 3. Что можно улучшить:

**Список данных для защиты и способы защиты**

| Данные                        | Способы защиты                              |
| ----------------------------- | ------------------------------------------- |
| Персональные данные пациентов | Контроль доступа, шифрование, обезличивание |
| Медицинские данные            | Контроль доступа, шифрование, обфускация    |
| Финансовые данные             | Контроль доступа, шифрование                |

**Инструменты:**

- Контроль доступа: ABAC, RBAC
- Шифрование: OpenSSL, AWS KMS
- Обфускация: DataSunrise, Delphix
- Тегирование данных: Apache Atlas, Alation
